Rules

  • Always write the Arabic name with its vowel marks: سَنَدي
  • Clear space around the logo = the height of the fatha mark on all sides
  • Minimum size: horizontal logo 120dp wide; mark 24dp
  • Use only the colour versions shown; never recolour, stretch, outline or add shadows
  • Body text at least 18sp; never Light or Thin weights
  • Sage is decoration only; use Sage Dark for secondary text
  • Quran text always uses an Uthmani (KFGQPC) font, never Tajawal
  • Warnings use dark orange, never bright red
